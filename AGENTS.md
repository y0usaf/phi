# AGENTS.md

Guide for AI coding agents working in the `phi` repository.

## Direction — read DESIGN.md first

`DESIGN.md` at the repo root is the source of truth for Phi's direction: a
pi-shaped minimal core with a Lua-canonical extension surface, rebuilt from
the salvage set (the pre-rebuild tree is preserved on `main`). It defines
**The Rule**:

> If a feature can be an extension, it must be an extension. The extension
> API is defined by what a Lua table can express; shipped defaults are
> embedded `.lua` registered through the same public API user extensions use.

Two standing corollaries: **no hook without an exerciser** (every API
addition lands with an example extension in the same commit), and **no
closed enums at the seam** (hosts dispatch on registered string keys, never
match on variants). Check `DESIGN.md`'s locked-decisions table before
relitigating an architectural choice, and update its roadmap checkboxes as
workstreams land.

## Project Overview

`phi` is a Rust workspace (edition 2024) built with [crane](https://github.com/ipetkov/crane) via Nix flakes. The binary entrypoint is `crates/phi-app` (produces the `phi` binary). See `README.md` for the crate layout.

## Architecture map — do not re-explore

`ARCHITECTURE.md` is a **generated** map of the workspace: the crate
dependency graph plus per-crate module/type/trait trees. It is regenerated by
`scripts/gen-arch.sh` and its freshness is enforced by `nix flake check`
(`checks.arch-fresh`), so it is always accurate — read it instead of spawning
exploration agents to map the codebase. For rationale, dataflow, and
invariants (which the generated map cannot capture), read `DESIGN.md`.
After adding/removing crates, modules, or public items, rerun
`scripts/gen-arch.sh` (jq and cargo-modules are in the dev shell) and commit
the result, or `arch-fresh` will fail.

## Build System — Nix is the Source of Truth

This project is built with Nix flakes (`flake.nix`) using crane. **Always compile and test through Nix, not through `cargo` directly.** This ensures the Nix store has up-to-date build artifacts so `nix run` is instant after a change — no recompilation needed.

### Commands

| Goal | Command | What it does |
|------|---------|--------------|
| **Compile the binary** | `nix build .#phi-app` | Builds `phi` into the Nix store; creates `result/` symlink |
| **Run the binary** | `nix run` | Runs `phi` — instant if `nix build` already ran |
| **Run tests** | `nix build .#checks.x86_64-linux.workspace-test` | Compiles + runs `cargo test` for the entire workspace through Nix |
| **Run all checks** | `nix flake check` | Evaluates and builds all `checks` outputs (tests, arch-fresh) |
| **Format Nix** | `nix fmt` | Runs `nixfmt` on `.nix` files |
| **Format Rust** | `cargo fmt` | Formats `.rs` files (safe; does not affect Nix store) |
| **Lint Rust** | `cargo clippy --workspace` | Run clippy (safe; does not affect Nix store) |

`cargo fmt` and `cargo clippy` are the sanctioned direct-cargo exceptions —
they don't produce build artifacts. For **compilation** and **tests**, use
the Nix commands.

**Gotcha:** the flake only sees git-tracked files. `git add` any newly
created file before `nix build`, or the build fails with "file not found
for module".

## Code Conventions

- **Rust edition**: 2024
- **Workspace lints**: `dead_code`, `unused`, `unreachable_code`, `unreachable_patterns` are set to `warn` (see `[workspace.lints.rust]` in `Cargo.toml`)
- **Formatting**: `cargo fmt` for Rust, `nix fmt` for Nix files
- **Crates**: all under `crates/`, auto-discovered via `members = ["crates/*"]`
- **Non-Rust files in src**: the Nix source filter includes `.json` and `.lua`
  (needed for `include_str!()` in phi-ai and the embedded Lua defaults). If
  you add new non-Rust file types that are `include_str!`'d, update the
  filter in `flake.nix`.

## Checklist

Before finishing a change:

1. `cargo fmt` — format Rust code
2. `nix build .#checks.x86_64-linux.workspace-test --print-build-logs` — run tests through Nix
3. `nix build .#phi-app` — compile the binary through Nix
4. `scripts/gen-arch.sh` if crates/modules/public items changed — commit the regenerated `ARCHITECTURE.md`
5. Verify `nix run` works
