# phi — port tracker

DESIGN.md is the spine (spec pin, the three divergences, locked decisions,
workstream list); this file is the ordered ladder inside the *current*
workstream only. Detail beyond this file lives in commits — if it grows past
~150 lines, it's absorbing what commits should say.

**The spec is `ref/pi` @ `c5582102` (pi v0.79.0).** Parity is judged
module-by-module against it; UI parity is judged side-by-side. The rebuild's
forgecode-visual calibration is retired: pi sets *both* the behavioral and
the visual bar now.

## Delivery target — exact interactive Phi, fastest non-throwaway path

The execution critical path is **finish WS3 → WS4 working agent → WS6 plus
interactive-required WS7 slices → WS8 exact default frontend**. WS5 provider
breadth is parallel/backfill work and must not block an Anthropic-backed
interactive Phi. This changes priority, never scope or acceptance: no
temporary UI, no Rust product-behavior shortcut, and no "close enough"
frontend. From the first UI slice, compare deterministic PTY/cell snapshots
and real adjacent-terminal sessions against pi v0.79.0. Parallel sessions must
own disjoint crates/files; the critical-path session owns PLAN.md.

**Immediate handoff:** begin WS6.1's differential renderer seam; keep WS5's
provider breadth parallel and non-blocking.

## Current — WS4: `packages/agent` as a Lua pack

Scope is the spec's `types.ts`, `agent-loop.ts`, and `agent.ts`. Product
behavior is embedded Lua; Rust supplies only stream/cancellation/schema and
coroutine-safe dispatch mechanisms. `proxy.ts` and `harness/**` remain later
WS5/WS7 consumers rather than entering the core loop.

- [x] **4.1 Contract + host mechanisms.** `phi-agent` now owns the embedded
      Lua state/mutator pack and typed open event envelope. `pi.ai.stream_simple`
      drains the existing typed stream into Lua and folds immediate failures
      into terminal assistant messages; cloneable abort signals, command/tool
      ctx, and prepare-then-coerce/validate tool arguments are public bindings.
      State copies/reset behavior and all bindings are exercised by examples
      and pi-derived tests. Full active-run subscriber/hook signal propagation
      lands with the lifecycle that owns it in 4.4.
- [x] **4.2 Deterministic streamed turn.** The embedded Lua pack now ports
      `streamAssistantResponse` and one-turn lifecycle ordering, transforms
      context before LLM conversion, resolves dynamic API keys per request,
      replaces partial transcript messages, and accepts a replaceable stream
      function. Public example plus pi-derived fixtures cover text, thinking,
      fragmented tool calls, custom-message filtering, and callback ordering.
- [x] **4.3 First working-agent gate — sequential tool round trip.** The Lua
      loop resolves public registered tools, prepares and validates arguments,
      runs before/after hooks and updates, converts failures to tool results,
      inserts results into the transcript, and automatically streams request
      two. A public fixture drives the embedded WS3 `write` tool from prompt to
      final text; pi-derived tests pin missing/invalid/throwing tool behavior.
- [x] **4.4 Stateful Agent + settlement.** The embedded Lua Agent now owns
      prompt/continue, transcript continuity, ordered subscriptions with
      reduction-before-listener state, active-run exclusion and abort signals,
      reset, terminal failure synthesis, and settlement after `agent_end`
      listeners. A public lifecycle example plus pi-derived tests cover
      multi-turn context, failure, abort, continuation, and runtime cleanup.
- [x] **4.5 Complete loop policy.** The Lua loop now drains steering before
      and between turns and follow-ups only at idle, with one-at-a-time/all
      queue modes and assistant-tail continuation. Turn preparation/stopping,
      all-results termination, global/per-tool sequential overrides, and
      default parallel execution match pi. Generic `pi.parallel` is Rust
      mechanism only and has a public exerciser; pi-derived tests pin
      completion-order tool-end events against source-order result persistence.
- [x] **4.6 Anthropic + CLI acceptance (headless slice).** The CLI loads
      the Lua agent, WS3 tools, and Anthropic stream seam; Lua emits streamed
      text and persists standard user/toolResult/assistant messages through
      the `phi-session` JSONL binding. The two-request local SSE replay in
      `crates/phi-app/tests/anthropic_replay.rs` is the CI acceptance gate.
      Rust remains model/auth, transport, and persistence mechanism only.
      Live credentialed verification of `phi "fix the failing test"` remains
      pending.
